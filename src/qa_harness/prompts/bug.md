Write a Jira bug report for a defect found by automated mobile tests. Engineers will act on it directly, so it must be precise, reproducible, and free of speculation. Use the evidence given; don't invent details. Steps to reproduce are user actions on the device, not test code. Severity follows impact on the user: Blocker (core flow unusable, no workaround), Critical (crash or data loss), Major (feature broken, workaround exists), Minor (cosmetic or edge case), Trivial.
